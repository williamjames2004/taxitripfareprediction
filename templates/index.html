Project Overview

About CabFare

A machine learning web application designed to estimate trip prices from historical trip information and pricing features.

Taxi Trip Price Prediction

The application uses a Random Forest Regressor trained on the supplied CSV dataset. It learns relationships between trip characteristics and recorded trip prices. A user can enter a new trip and receive a predicted price from the saved model.

Dataset Information

Understand the Data

The model uses the following ten input columns and learns to predict the target column, Trip_Price.

Column Name Type Description
Trip_Distance_km Numeric Distance travelled during the trip, in kilometres.
Time_of_Day Categorical Time period of the trip: Morning, Afternoon, Evening, or Night.
Day_of_Week Categorical Whether the trip takes place on a Weekday or Weekend.
Passenger_Count Integer Number of passengers travelling in the taxi.
Traffic_Conditions Categorical Traffic level recorded as Low, Medium, or High.
Weather Categorical Weather condition recorded as Clear, Rainy, or Cloudy.
Base_Fare Numeric Base amount used in the fare calculation.
Per_Km_Rate Numeric Fare rate applied per kilometre.
Per_Minute_Rate Numeric Fare rate applied per minute.
Trip_Duration_Minutes Numeric Estimated trip duration, in minutes.
Trip_Price Target Recorded trip price that the model learns to predict.
Important: The sample dataset does not identify the fare currency. The application therefore displays the prediction as a numeric amount without assigning a currency symbol. Use the currency and units specified by your actual dataset.
Model Details

Random Forest Regressor

The model trains multiple decision trees and combines their outputs to estimate trip prices.

01

Load and Prepare the Dataset

Pandas loads the CSV file. Missing values are filled using forward fill and backward fill before separating input features and the target.

02

Encode Categorical Features

OneHotEncoder converts text features such as time of day, day type, traffic, and weather into a numerical representation. Unknown categories are ignored by the encoder.

03

Train the Random Forest

The model uses 200 decision trees. Each tree learns patterns from the training records, and their outputs are combined into a final regression prediction.

04

Evaluate and Save

When there are enough records, the code evaluates a train-test split using Mean Absolute Error and, when appropriate, the R² score. It then trains on all available records and saves the pipeline as trip_price_model.pkl.

05

Predict a New Trip

Flask receives the form data, validates the values, creates a DataFrame with the expected feature names, and passes it to the saved model for prediction.

Why Random Forest?

Random Forest can learn non-linear relationships and interactions between trip variables. Combining many trees can reduce the variance of an individual tree.

Algorithm: Random Forest Regressor

Number of trees: 200

Random state: 42

Evaluation: MAE and R² when applicable

Model limitation: prediction quality depends on the size, quality, and representativeness of the training dataset. A very small sample cannot establish reliable real-world fare accuracy.

Project Notes

Responsible Fare Estimation

CabFare is a machine learning demonstration. Its predictions depend on the data used to train the model.

Prediction, Not a Guarantee

A predicted price can differ from an actual taxi fare. Real prices may include surcharges, tolls, waiting charges, local regulations, and operator-specific rules that are not represented in the dataset.

Dataset Quality Matters

Reliable results require sufficient, representative training examples. The single sample row shown in the question is not enough to train a reliable model or evaluate its real-world performance.
